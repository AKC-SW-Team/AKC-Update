# AKC Update

Public update distribution repository for AKC PMS and AKC SMS.

Upload release assets to the latest GitHub Release:

- `AKC-PMS-update.json`
- `AKC-PMS-Setup.exe`
- `AKC-SMS-update.json`
- `AKC-SMS-Setup.exe`

The applications read update manifests from:

- `https://github.com/AKC-SW-Team/AKC-Update/releases/latest/download/AKC-PMS-update.json`
- `https://github.com/AKC-SW-Team/AKC-Update/releases/latest/download/AKC-SMS-update.json`
